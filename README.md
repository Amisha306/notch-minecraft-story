# From Blocks to Billions: The Notch Story

A creative biography webpage about **Markus "Notch" Persson**, the creator of Minecraft.

## About This Project

This webpage tells the entrepreneurial journey of Notch — from a self-taught Swedish programmer to the creator of the best-selling video game in history, and the $2.5 billion sale of Mojang to Microsoft.

## Features

- Modern dark theme with Minecraft-inspired design
- Storytelling layout (not a dry Wikipedia clone)
- Hero section with photo support
- Timeline of key events
- Success metrics and achievements
- Personal struggles and legacy

## How to View

1. Open `index.html` in any web browser
2. To add photos:
   - Place `notch.jpg` (photo of Markus Persson)
   - Place `minecraft.jpg` (Minecraft related image)
   - Keep both files in the same folder as `index.html`
